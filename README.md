simple node.js progress bot for bluesky 
can be found @ [https://bsky.app/profile/humiliationcentury.bsky.social](https://bsky.app/profile/humiliationcentury.bsky.social)

- runs on chron github action to post everyday at noon EST 
- uses polyfill for JS Temporal for progress percentage calculations [https://github.com/js-temporal/temporal-polyfill](https://github.com/js-temporal/temporal-polyfill)
